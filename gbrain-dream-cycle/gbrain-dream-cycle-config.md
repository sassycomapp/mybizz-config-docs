## Known limitation (active, not historical)

`resolve_symbol_edges` does not produce a fully resolved code call-graph —
`code` is `extractable: false` in every bundled pack; `code-callers`/
`code-callees` return symbol names only (`resolved: false`). Graphify's
`get_neighbors` is the correct tool. Double-verified; permanent.
