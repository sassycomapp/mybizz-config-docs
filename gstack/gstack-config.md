## Install topology

All symlinks listed here are created by GStack's own setup, upgrade and
relink tools — none are manual. Those tools read the `skill_prefix` setting
(`false` here), so they create plain shortcuts only. One real copy of every
file lives in the clone; OpenCode discovers skills through links into it.

| Element | State |
|---|---|
| Real per-host skill tree | `/mnt/c/mybizz/gstack/.opencode/skills/` — 54 entries (53 `gstack-<name>` + the `gstack` aggregate). 6 of the 53 have no OpenCode shortcut because they cannot run on this PC (verified 2026-10-03): `claude` (calls the Claude Code program, which this PC does not run), `ios-qa`, `ios-fix`, `ios-design-review` (need a Mac with Xcode and a paired iPhone), `ios-clean`, `ios-sync` (only remove or regenerate the debug bridge `ios-qa` installs into an iOS app — without `ios-qa` they have nothing to work on) |
| Discovery — skill shortcuts | `~/.config/opencode/skills/<declared-name>` → `/mnt/c/mybizz/gstack/.opencode/skills/gstack-<name>/` — 47 shortcuts, one per installed gstack skill, named by the skill's declared frontmatter `name:` (46 plain names + `gstack-upgrade`, the one skill declaring the prefixed name). No `gstack-`-prefixed shortcut exists. OpenCode loads a skill only when its `name:` matches the folder containing it, so each shortcut carries exactly the declared name. Created by the setup/upgrade/relink tools reading `skill_prefix: false` (verified 2026-10-03) |
| Aggregate entry | `~/.config/opencode/skills/gstack/` — hybrid real dir: `SKILL.md`, `ETHOS.md`, `bin` are symlinks into the clone; `browse/`, `design/`, `gstack-upgrade/`, `plan-devex-review/`, `qa/`, `review/` are real subdirs |
| `GSTACK_BIN` | `~/.config/opencode/skills/gstack/bin` → `/mnt/c/mybizz/gstack/bin` — regenerated by every setup run; actively used by skills |
| Install / refresh | `cd /mnt/c/mybizz/gstack && ./setup --host opencode` |
