# Durable fact — Archify scoping skill pre-work

skill: restates the developer's intent in one paragraph, runs a bounded guiding
interview, reads the source material, chooses the diagram type via
`archify guide "<scenario>" --json`, and produces an approved **Scope Card**
(`archify/output/{subject}-scope.md` markdown + `{subject}-header.json` machine
contract) before any Archify authoring begins. A nodes-only feasibility probe
(stages/components + boundary, no connections) runs before connecting — it
catches overlap and desktop-readability/font-scale failures pre-flight.
