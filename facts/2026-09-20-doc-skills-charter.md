# Durable fact — The three documentation skills' charter

The three documentation skills exist to: A) resolve the routing files
(dotfiles and canonical system files); B) resolve inter-file links;
C) reformat links into [[wikilink]] form so GBrain can follow them.
File moves, file renames, and references to not-yet-built documents are
developmental states — never error states, never to be remediated by these
skills. Any skill behaviour beyond the charter (moving, renaming, retiring,
forcing content into a paradigm) is out of scope and damaging.
Developer-stated 2026-09-20.
