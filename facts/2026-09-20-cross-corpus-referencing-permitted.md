# Durable fact — Cross-corpus referencing is permitted

A local document referencing a document in another project library is normal
and permitted (developer ruling 2026-09-20). Cross-corpus references whose
targets have unique basenames convert to wikilinks like any other match.
The F-MK1 healed-prose form — `stem.md (owning project library)` — is the
sanctioned cross-corpus pattern and is never re-converted. Supersedes the
"Local → Local, cross-project: never live" row as written in the
mb-align-docs skill (skill-text correction still pending).
