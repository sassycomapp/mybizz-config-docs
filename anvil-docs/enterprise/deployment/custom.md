# [Custom Deployment](#custom-deployment)

If you can’t use [Docker](docker) or [Kubernetes](kubernetes) to deploy Anvil, please [get in touch](mailto:sales@anvil.works) to discuss custom deployment packages. Anvil only requires Python and a JVM, so chances are we can put together a custom deployment solution that works for you.
