# [Legacy Full Python Packages](#legacy-full-python-packages)

Anvil’s legacy ‘Full Python’ [server environment options](/docs/server/custom-packages#available-python-versions) run an ordinary CPython interpreter, just like you would run on your own machine. There is a long list of packages already installed in the legacy Full Python 3 server environment.

**Python 3.10** is now the default Anvil server enviroment. It allows you to install any package you like. [Learn how to do it here](/docs/server/custom-packages#adding-packages).

Free Plan users can’t enable the legacy Full Python interpreter. However, if you’re on a Free Plan, you can use the [Python 3.10 server environment](/docs/server/custom-packages) and [install packages yourself](/docs/server/custom-packages#adding-packages).
