# [Version Control and Collaboration](#version-control-and-collaboration)

The Anvil Editor has built-in version control to help you track changes made to your app and collaborate with other developers

Within Anvil, you can create branches, commit changes and resolve conflicts. Every Anvil app is a [Git](https://git-scm.com/) repository, and you can also connect to external Git repositories, such as one hosted on [GitHub](https://github.com/).
