# [Stripe Integration](#stripe-integration)

[Tutorial: Payments with Stripe](/learn/tutorials/stripe)

### Take payments and subscriptions

Anvil has a built-in integration with Stripe that means you can run a payment form with a single line of code.

Run through the [Quickstart](stripe/quickstart) to see how it works.

You can also:

-   take payments programmatically without displaying the built-in payment form
-   associate payments with a particular customer record in your Stripe account
-   store their payment methods
-   and set up recurring subscriptions.

There’s a test mode and a live mode, so you can test your code without money changing hands.

See [Payments and Subscriptions](stripe/payments-and-subscriptions) for all the details on the Stripe service.

Stripe apply a transaction fee to payments you receive through Stripe - [see their pricing page](https://stripe.com/pricing) for more information. This price is the same as if you use Stripe directly (Anvil do not take an extra fee).
