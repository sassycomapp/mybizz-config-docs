# [Deploying your App](#deploying-your-app)

Anvil apps are automatically hosted - all you need to do is click a button to publish them on the Internet.

Check the [Quickstart](deployment/quickstart) to how to publish an app. This page will go into more detail about how it all works.

## [Deployment Environments](#deployment-environments)

To make your app available to others, you will need to create a deployment environment. A deployment environment says, “for this URL (or this Uplink key), load this version of the app, with this configuration”.

See [Deployment Environments](deployment/environments) for more information.

## [Importing other apps](#importing-other-apps)

Your apps can add other apps as dependencies. This means you can re-use Forms and code, and build apps in a modular way.

See [Depending On Other Apps](deployment/dependencies) for more information.

## [Deploy on your own hardware](#deploy-on-your-own-hardware)

You can export Anvil apps from the cloud editor, and host them on any computer, using the open-source [Anvil App Server](https://github.com/anvil-works/anvil-runtime).

## [Anvil on-site](#anvil-on-site)

You can get a full installation of the whole Anvil system – both the editor, for building your apps, and the one-click hosting platform for deploying them – in your private network, or in your own cloud environment, as part of an Enterprise installation.

See [Anvil Enterprise](/docs/overview/enterprise) for more information.

## [Hosting Location](#hosting-location)

Anvil’s infrastructure currently lives in London (AWS eu-west-2).
