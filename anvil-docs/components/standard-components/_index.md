# [Standard Anvil Components](#standard-anvil-components)

The Standard Anvil Components are Anvil’s original set of components. This component library consists of a number of basic components, like Buttons and TextBoxes, as well as [Container](standard-components/containers) components for laying out your pages. In the Standard Anvil component library, you’ll find:

-   [Basic Components](standard-components/basic) - things like Buttons, Links and Images.
-   [Containers](standard-components/containers) - these group components together and define where they sit on the page.
-   [RepeatingPanels](standard-components/repeating-panel) - these repeat the same group of components for all items in a given list.
-   [Data Grids](standard-components/data-grids) - these are an easy and powerful way to create a paginated table.
-   [Plots](standard-components/plots) - these display data using Plotly.
-   [Maps](standard-components/maps) - Google Maps in Python.
-   [Canvas](standard-components/canvas) - these provide area where you can draw graphics, like an HTML canvas but in Python.
-   [HTMLComponent](standard-components/html-component) - Anvil represents native HTML elements as HTMLComponents.
