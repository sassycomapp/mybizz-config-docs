# [Welcome to Anvil.](#welcome-to-anvil)

Anvil is a new way to build web apps, with nothing but Python. This documentation will tell you all about how it works.

## [Getting Started with Anvil](#getting-started-with-anvil)

If you are just starting out with Anvil, check out our [Get Started documentation](/docs/get-started). There you can find an introductory tutorial and other resources to help you on your journey to becoming an Anvil developer.

## [Structure of an Anvil app](#structure-of-an-anvil-app)

An Anvil app is made up of:

-   A [User Interface](/docs/client), which you design with a drag-and-drop designer
-   [Client-side Python code](/docs/client/python), which runs in the web browser
-   [Server-side Python code](/docs/server), which runs on Anvil’s servers
-   A built-in database ([Data Tables](/docs/data-tables)), which stores your data
-   (Optionally:) Some Python code [running on your computer](/docs/uplink), which can also interact with your app

Want to learn more about how Anvil works? Read our brief [introduction to Anvil](/docs/get-started/how-does-it-work).

## [What else you can do](#what-else-you-can-do)

Anvil also has built-in support for:

-   One-click [hosting and deployment](/docs/deployment)
-   Versioning your app with [Git version control](/docs/version-control)
-   Sending and receiving [emails](/docs/email)
-   Exposing and using [HTTP APIs](/docs/http-apis)
-   Integrating with services from:
    -   [Google](/docs/integrations/google)
    -   [Microsoft](/docs/integrations/microsoft)
    -   [Facebook](/docs/integrations/facebook)
    -   [Stripe](/docs/integrations/stripe)
    -   …and [anything else with a Python SDK](/docs/server/python-versions/packages)!
