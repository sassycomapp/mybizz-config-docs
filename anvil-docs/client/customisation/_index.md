# [Customisation](#customisation)

Anvil provides several ways to customise your app’s appearance and behaviour. You can apply colour schemes and CSS to control how your app looks, build your own reusable components, add your own asset files, or interact directly with JavaScript from the Anvil Editor.

## [](#colour-schemes)[Colour Schemes](/docs/client/customisation/colour-schemes)

Many Anvil themes come with built-in colour schemes which you can use or modify to change the look of your app.

## [](#custom-components)[Custom Components](/docs/client/customisation/custom-components)

You can create your own reusable component types by using a Form as a custom component. Custom components can appear in the Toolbox alongside built-in Anvil components, with configurable properties and events. You can build them from a standard [Anvil Form](/docs/client/forms), or [from scratch using HTML](/docs/client/customisation/custom-components/html-components).

## [](#assets)[Assets](/docs/client/customisation/assets)

You can add your own files to your app, such as HTML files, CSS, JavaScript or images. Assets can be referenced from your theme, HTML templates, or directly using their URL.

## [](#using-css)[Using CSS](/docs/client/customisation/using-css)

Anvil themes are built on HTML and CSS files you can edit directly. You can define [Roles](/docs/client/customisation/using-css/roles), [write your own CSS rules](/docs/client/customisation/using-css/roles#changing-the-components-style-in-css), and [customise specific UI elements](/docs/client/customisation/using-css/loading_indicator).

## [](#using-javascript)[Using JavaScript](/docs/client/customisation/javascript)

Client-side code in Anvil is compiled to JavaScript and runs in the browser. This means you can interact with JavaScript libraries from your Python code, or write JavaScript directly.
